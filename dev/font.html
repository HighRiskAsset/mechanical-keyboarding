dev/font.html: the font sheet alone, from dev/gen/pixels.js → /upload. The full bake (dev/bake.html) is a v3 page and stops before it reaches the font; this one bakes just font.png + font.json, the same cells in the same order and the same shelf-packing, so every glyph already on the sheet keeps its place.

Default target is assets/inbox. Open with ?to=sprites to write the live sheet, which is refused if any cell the sheet already has would move or change (add &force to overwrite a repainted glyph on purpose).
